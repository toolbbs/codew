# codew 改名第一阶段

当前工作树基于正式 V0.7.8 源码，只完成品牌及源码命名调整，尚不可发布、安装或替换已有服务器。

## 已调整

- 页面标题、登录页、导航品牌、仪表盘和 BBR 可见品牌文字改为 codew；沿用原布局与样式。
- 前端包名改为 codew-frontend，不更换依赖或版本。
- 浏览器认证、前端版本和落地书签存储键改为 codew 前缀，不自动读取或迁移旧品牌本地数据；用户需重新登录。
- Go 模块改为 codew/backend 与 codew/agent，并同步内部 import；不改 API 路由、数据模型、业务处理和 Agent 协议。
- 启动日志及诊断报告标题改名；对应版本检查和浏览器测试夹具同步调整。

## 本阶段明确保留

版本仍为 0.7.8-stable-engineering。VERSION、版本显示、正式清单、历史文档、旧 Release 和安装包均不更新。

CLI、安装目录、配置与数据库路径、环境变量、服务名、健康接口的 service 值、Nginx/Docker 配置、下载地址、包名和备份格式暂时保留旧名称，待下一阶段统一处理。页面中的操作命令及服务器安装说明因此仍可能显示旧名称，不能宣称全产品改名已完成。

WebSocket 路径、gRPC 服务名、SOCKS 用户名及 Reality 后备值属于连接参数，不作为品牌文本替换。Xray 文件可能仅因模块名变化调整 import，不修改配置生成或 Reality 行为。

BBR 提示补丁保留在原独立工作树，本阶段不纳入。已发布二进制与 frontend/dist 不覆盖，当前源码与冻结产物品牌不同；阶段二完成后必须重新构建、验收才能交付。

## 发布与迁移边界

本阶段不创建或推送新仓库，不修改旧服务器，不支持新旧产品同机共存，不迁移旧数据或备份。历史文件及版权/许可证声明保留，不通过改名清除来源。源码 AGPL 标记与 LICENSE_STRATEGY.md 的声明差异仍需发布前核清。

新仓库地址拟为 toolbbs/codew，尚未验证其存在或建立正式发布资产，不能提前替换清单指向未存在的安装包。

## 验收与回滚

验证 Go 模块和内部依赖、后端回归、Linux Agent 编译/测试及前端类型检查/隔离构建。浏览器在回环预览和合成 API 下检查桌面/手机品牌、登录状态隔离、退出与401行为；不使用真实账号或数据。

外部工作区备份保留正式基线与失败记录。出现失败停止，按本阶段明确差异进行授权恢复，不 reset、stash 或覆盖原工作区。本工作树不合并、不提交、不发布，不自动进入第二阶段。
